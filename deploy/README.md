# NEXUS — website (deploy bundle)

Self-contained single-file site (`index.html`): zero dependencies, zero storage.

- **Test:** open `index.html`, or `python3 -m http.server`
- **Deploy free:** drag this folder to Netlify Drop / Cloudflare Pages / Vercel / GitHub Pages
- **Configs included:** `netlify.toml`, `vercel.json`, `robots.txt`
- **Full guide:** see `DEPLOY.md` and `DEPLOY-FREE.md`
